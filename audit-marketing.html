catégorie par catégorie.

Performance

  • Poids des images

    4,2 Mo chargés dès l’arrivée sur la page. Cible raisonnable : moins de 1 Mo.

  • Temps d’affichage mobile

    4,1 secondes avant que la page soit utilisable. Cible : moins de 2,5 secondes.

  • Compression du texte

    Le HTML et le CSS sont bien compressés à l’envoi.

Référencement

  • Aucune balise de description

    Google affiche un extrait choisi au hasard dans la page.

  • Titre de page générique

    La page d’accueil s’appelle simplement « Accueil » dans les résultats de recherche.

  • Site indexé

    Google connaît et référence déjà le site.

Mobile

  • Bouton de réservation caché

    Il faut faire défiler toute la page pour le trouver sur téléphone.

  • Texte lisible

    Aucun zoom nécessaire pour lire le contenu.

Confiance & contact

  • Connexion sécurisée

    Le certificat HTTPS est valide et à jour.

  • Téléphone non cliquable

    Le numéro affiché n’ouvre pas l’appel sur mobile.

  • Formulaire de contact

    Le test d’envoi n’a pas abouti : le message ne part pas.

Recommandations

Ce qui compte,
dans l’ordre.

  1. 1 · Effort léger

    Des photos qui retardent l’ouverture

    Le visiteur attend avant de pouvoir consulter la carte.

    Action : alléger les photos et charger celles du bas de page plus tard.

    Effet estimé : ouverture 2 fois plus rapide

  2. 2 · Effort léger

    Un bouton de réservation trop discret

    Sur téléphone, il faut parcourir toute la page pour le trouver.

    Action : rapprocher le bouton de la carte et des horaires.

    Effet estimé : moins d’abandons avant réservation

  3. 3 · Effort modéré

    Une présentation trop vague sur Google

    Le type de cuisine et le quartier sont difficiles à identifier.

    Action : préciser l’activité et le lieu dans le titre et la description du site.

    Effet estimé : mieux ressortir sur les recherches locales

  4. 4 · Effort modéré

    Un formulaire de contact qui ne fonctionne pas

    Les demandes envoyées depuis le site n’arrivent nulle part.

    Action : reconnecter le formulaire et vérifier la réception avant la mise en ligne.

    Effet estimé : zéro demande perdue en silence
